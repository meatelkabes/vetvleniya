## Цель
Освоение базового синтаксиса C++ и математических вычислений на примере расчета характеристик газожидкостной смеси. Изучение работы циклов (на примере `for`) и условных операторов (ветвлений `if-else`).

## Описание
Программа вычисляет число Фруда (`Fr`) и коэффициент газонасыщенности смеси (`φ`) для заданного набора скоростей.

Число Фруда рассчитывается по формуле:
`Fr = v^2 / (g * d)`
где `v` — скорость смеси, `g` — ускорение свободного падения, `d` — диаметр трубы.

Коэффициент газонасыщенности рассчитывается по одной из двух формул в зависимости от значения числа Фруда (реализовано через ветвление `if-else`):
- Если `Fr < 50`, то `φ = 0.05 * Fr^0.2`
- Если `Fr >= 50`, то `φ = 0.35 * Fr^0.1`

Для перебора заданных скоростей используется цикл `for`. Вывод результатов производится только для значений скорости: 1, 2, 5, 10, 20 и 50 м/с.

## Исходные данные
Константы, заданные в коде:
- Диаметр трубы (`diameter`) = 0.191 м (19.1 см)
- Ускорение свободного падения (`gravity`) = 9.81 м/с²

Значения скорости (`v`), для которых выполняется расчет: 1, 2, 5, 10, 20, 50 м/с (перебираются в цикле).

## Ожидаемые результаты
Программа выводит на экран значения для каждой из заданных скоростей:
- `speed` — скорость смеси (v)
- `frudNum` — рассчитанное число Фруда (Fr)
- `gasSaturationCoefficient` — рассчитанный коэффициент газонасыщенности (φ)

- При v = 1: Fr = 0.533, φ = 0.044
